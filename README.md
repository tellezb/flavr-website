# Flavr Website

Official homepage for Flavr - Your culinary journey companion.

## About

This is the GitHub Pages site for Flavr, a recipe discovery and cooking management app. The site showcases Flavr's three flagship features:

- 🧭 **Discover** - Find new recipes & trending dishes
- 👨‍🍳 **Cook** - Manage your recipe collection
- 🌱 **Grow** - Track your culinary journey

## Technology

- Pure HTML, CSS, and vanilla JavaScript
- Responsive design
- Smooth scroll animations
- Mobile-friendly

## Local Development

Simply open `index.html` in your browser to view the site locally.

The homepage uses locally stored App Store artwork and a separate framed hero
screenshot in `assets/images/app-screenshots/`. When updating the listing images,
refresh the corresponding gallery images as well, keeping their full artwork,
descriptive alt text, dimensions, and optimized file sizes. The gallery supports
manual scrolling without JavaScript and, when enabled, provides position dots and
advances every three seconds. Interaction pauses automatic advances until five
seconds of inactivity; automatic motion is disabled for reduced motion.
